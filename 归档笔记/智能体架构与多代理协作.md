## 条目 1：nanobot 初始化与运行链路
来源：`nanobot项目整体逻辑与上下文机制总结_2026-03-11_17-20-04.md`

- 入口由 `onboard` 初始化配置与记忆文件，再由 `gateway` 读取配置并实例化 `agentloop`。
- `gateway` 将 agent 注入 cron/heartbeat 回调；cron 产出会进入 `outbusmessage`，heartbeat 主要执行周期任务并记录日志。
- `bus` 在 channel、agent、cron 之间复用，承担入站/出站消息收集与分发。

## 条目 2：上下文与子 Agent 返回机制
来源：`nanobot项目整体逻辑与上下文机制总结_2026-03-11_17-20-04.md`

- 上下文核心包括记忆文件、历史对话、always 技能、技能摘要与图片编码内容。
- 子 Agent 的结果通常不是同轮即时返回，而是写入入站消息，主 Agent 在后续循环消费。

## 条目 3：多代理协作模式对比
来源：`多代理协作模式学习理解_2026-03-18_10-53-15.md`

- 模式 A：独立子代理并行执行独立任务，目标是提速与减少上下文污染。
- 模式 B：团队协作子代理（共享任务面板/状态 + Team Lead 协调），适合中低耦合拆分，不适合强顺序强耦合任务。
