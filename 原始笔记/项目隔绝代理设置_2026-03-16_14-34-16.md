﻿项目隔绝代理设置结论：

第一次实例化客户端对象时（如 `OpenAI(...)` / `httpx.Client(...)`）就会决定是否读取代理环境变量，所以必须在主程序入口导入其它模块之前设置 `NO_PROXY`，建议直接放在入口文件顶部。

```python
import os
os.environ["NO_PROXY"] = "api.deepseek.com,dashscope.aliyuncs.com"
os.environ["no_proxy"] = os.environ["NO_PROXY"]
```
