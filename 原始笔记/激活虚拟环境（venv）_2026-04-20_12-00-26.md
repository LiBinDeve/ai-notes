## 原文（保留）

```text
# ── 环境初始化（首次） ────────────────────────────────

# 1. PowerShell 授权（允许执行脚本）
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

# 2. 创建虚拟环境
python -m venv venv

# 3. 激活虚拟环境（PowerShell）
.\venv\Scripts\Activate.ps1

# 4. 拉取 wechat-cli 源码
git clone https://github.com/huohuoer/wechat-cli.git

# 5. 安装依赖（在已激活的虚拟环境中）
pip install -r requirements.txt
pip install sqlalchemy streamlit

# 6. 安装 wechat-cli（可编辑模式，源码修改后立即生效，因为需你环境中只是指向源码目录，而不是复制源码到环境中）
pip install -e wechat-cli

# 5. 保存依赖
pip freeze > requirements.txt

# ── 每次启动 ─────────────────────────────────────────

# 激活虚拟环境（PowerShell）
venv\Scripts\activate

# 运行 Streamlit UI
streamlit run app.py

# 运行 AI 分析（手动触发）
python analyzer.py


# ── 常用验证命令 ──────────────────────────────────────

# 测试 wechat-cli 是否正常（先用微信联系人备注名试一下）
wechat-cli history "联系人备注名" --format text

# 查看已安装的包
pip list
```

## 整理版（更适合直接复制执行）

### 首次初始化（PowerShell）

```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
python -m venv venv
.\venv\Scripts\Activate.ps1

git clone https://github.com/huohuoer/wechat-cli.git
python -m pip install sqlalchemy streamlit
python -m pip install -e wechat-cli
```

### 每次启动

```powershell
# PowerShell 激活 venv（更常见写法）
.\venv\Scripts\Activate.ps1

streamlit run app.py
python analyzer.py
```

### 常用验证

```powershell
wechat-cli history "联系人备注名" --format text
python -m pip list
```

## 备注
- 如果在 `cmd.exe` 下激活，一般是 `venv\Scripts\activate.bat`；在 bash/zsh 下是 `source venv/bin/activate`。
