# PyAutoGUI 批量网页操作脚本笔记
Excel 批量读取数据 → 手动标定页面坐标 → 计算截图区域 → 循环执行浏览器操作 → 保存结果

## 读取数据
打开 Excel
遍历所有工作表
从第 2 行开始读取
读取第 1 列
去掉空值
转成字符串
返回单号列表
```python
def load_numbers():
    wb = openpyxl.load_workbook(EXCEL)
    numbers = []
    for ws in wb.worksheets:
        for row in ws.iter_rows(min_row=2, values_only=True):
            if row[0]:
                numbers.append(str(row[0]).strip())
    return numbers
```

## 获取坐标
input函数有两个特性：第一，input() 是一个阻塞函数，程序运行到这一行时会完全停下来，等待用户按下 Enter（回车键）。在按下回车之前，后面的代码不会执行。第二，input() 不仅能等待，还能捕获用户在命令行输入的内容。它会把用户输入的文字作为字符串返回，你可以把它赋值给一个变量，name = input("请输入你的名字：")。
```python
os.makedirs(OUTPUT, exist_ok=True)
numbers = load_numbers()
print(f"共 {len(numbers)} 个单号\n")

print("请用自己的浏览器打开查询页面并最大化窗口")
input("准备好后按 Enter\n")

input("将鼠标移到【单号输入框】，按 Enter 记录位置...")
input_pos = pyautogui.position()
print(f"  已记录: {input_pos}")

input("将鼠标移到【查询按钮】，按 Enter 记录位置...")
search_pos = pyautogui.position()
print(f"  已记录: {search_pos}\n")

input("将鼠标移到【清除按钮】，按 Enter 记录位置...")
clear_pos = pyautogui.position()
print(f"  已记录: {clear_pos}\n")

input("将鼠标移到【截图区域左上角】，按 Enter 记录位置...")
top_left = pyautogui.position()
print(f"  已记录: {top_left}")

input("将鼠标移到【截图区域右下角】，按 Enter 记录位置...")
bottom_right = pyautogui.position()
print(f"  已记录: {bottom_right}\n")
```

## 计算截图区域
通过左上角和高度、宽度确定区域。
```python
left = min(top_left.x, bottom_right.x)
top = min(top_left.y, bottom_right.y)
width = abs(bottom_right.x - top_left.x)
height = abs(bottom_right.y - top_left.y)
region = (left, top, width, height)
print(f"截图区域: {region}\n")
```

## 执行操作
```python
for i, num in enumerate(numbers, 1):
    print(f"[{i}/{len(numbers)}] {num}", end=" ", flush=True)

    # 点击清除按钮，清空上一个订单号
    pyautogui.click(clear_pos)
    time.sleep(0.5)

    # 点击输入框，粘贴新单号
    pyautogui.click(input_pos)
    time.sleep(1)  # 等待输入框获得焦点
    pyperclip.copy(num)  # 复制到剪贴板
    pyautogui.hotkey("ctrl", "v")  # 粘贴
    time.sleep(1)

    # 点击查询
    pyautogui.click(search_pos)
    time.sleep(12)  # 预留足够时间等待页面加载和手动处理验证码

    # 截图（指定区域）
    path = os.path.join(OUTPUT, f"{num}.png")
    screenshot = pyautogui.screenshot(region=region)
    screenshot.save(path)
    print("已保存")

print(f"\n全部完成，截图在 {OUTPUT}/")
```
