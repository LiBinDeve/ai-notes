## 1. 创建 Word 文档对象

### 新建文档
```python
from docx import Document

doc = Document()
```

说明：
- `Document()` 就是创建一个新的 Word 文档对象。
- 后续所有段落、样式、图片都挂在这个对象下面。

在这份代码里封装成了：
```python
def create_doc():
    doc = Document()
    return doc
```

## 2. 中文字体设置的关键细节

### 只设 `font.name` 不够
这份代码专门写了一个函数处理中文字体：

```python
from docx.oxml.ns import qn
from docx.oxml import OxmlElement

def set_chinese_font_for_style(style, font_name='仿宋'):
    rPr = style._element.get_or_add_rPr()
    rFonts = rPr.find(qn('w:rFonts'))
    if rFonts is None:
        rFonts = OxmlElement('w:rFonts')
        rPr.append(rFonts)
    rFonts.set(qn('w:eastAsia'), font_name)
```

说明：
- `python-docx` 里，中文字体不能只靠 `style.font.name = '仿宋'`。
- 还要设置 `w:eastAsia`，否则 Word 里中文部分可能不会按预期字体显示。
- 这里是直接操作底层 XML，把东亚字体写进去。

实用理解：
- `font.name` 更像设置西文字体。
- `rFonts.set(qn('w:eastAsia'), ...)` 才是中文字体真正生效的关键补丁。

## 3. 创建自定义段落样式

### 新增样式
```python
from docx.enum.style import WD_STYLE_TYPE
from docx.shared import Pt
from docx.shared import RGBColor

style_main = doc.styles.add_style('MyMainStyle', WD_STYLE_TYPE.PARAGRAPH)
style_main.base_style = doc.styles['Normal']
style_main.font.name = '仿宋'
style_main.font.size = Pt(16)
style_main.font.bold = False
```

说明：
- `doc.styles.add_style(name, WD_STYLE_TYPE.PARAGRAPH)` 用来创建段落样式。
- `base_style` 设成 `Normal`，表示在默认样式上扩展。
- 字号用 `Pt(...)`。
- 颜色可用 `RGBColor(...)` 设置。

这份代码里定义了几个样式：
- `MyMainStyle`：正文样式
- `MyHeadingStyle`：一级小标题
- `MyGraghHeadingStyle`：图标题
- `MyTitleStyle`：主标题

标题样式的颜色写法：
```python
style_title.font.color.rgb = RGBColor(0xFF, 0x00, 0x00)
```

说明：
- `font.color.rgb` 用来设置字体颜色。
- 这里写的是红色标题。

## 4. 添加段落

### 基本写法
```python
para = doc.add_paragraph(text)
```

说明：
- `add_paragraph(...)` 是最常用的写正文和标题的方法。
- 如果不传内容，也可以先建空段落，再往里加 `run`。

例如：
```python
note_one = doc.add_paragraph()
note_one_run = note_one.add_run('2026年第4月')
```

## 5. 给段落套样式

### 设置段落样式
```python
para.style = 'MyMainStyle'
```

说明：
- 先用 `ensure_styles(doc)` 创建样式。
- 后面写段落时直接指定样式名即可复用字体、字号、粗细等配置。

这份代码里的典型写法：
```python
heading1 = doc.add_paragraph(text)
heading1.style = 'MyHeadingStyle'
```

## 6. 设置段落对齐和缩进

### 对齐方式
```python
from docx.enum.text import WD_ALIGN_PARAGRAPH

para.paragraph_format.alignment = WD_ALIGN_PARAGRAPH.CENTER
```

常见值：
- `WD_ALIGN_PARAGRAPH.LEFT`
- `WD_ALIGN_PARAGRAPH.CENTER`
- `WD_ALIGN_PARAGRAPH.RIGHT`
- `WD_ALIGN_PARAGRAPH.JUSTIFY`

这份代码里实际用了：
- 标题居中
- 提示文字右对齐
- 正文两端对齐

### 首行缩进
```python
para.paragraph_format.first_line_indent = Pt(28.2)
```

说明：
- 正文首行缩进直接设在 `paragraph_format` 上。

### 左缩进和右缩进
```python
para.paragraph_format.left_indent = Pt(28.2)
para.paragraph_format.right_indent = Pt(28.2)
```

说明：
- 一级标题、二级标题和提示语都用了段落缩进控制版式。

### 行距
```python
para.paragraph_format.line_spacing = 1.1
```

说明：
- 这份代码里正文行距设成 `1.1`。

## 7. 用 run 设置局部文字属性

### 添加 run
```python
run = para.add_run(text)
```

说明：
- `run` 是段落里的文字片段。
- 当一段里需要单独改字体、字号、下划线时，通常就用 `run`。

### 设置字体和字号
```python
run.font.name = '仿宋'
run.font.size = Pt(16)
```

### 设置下划线
```python
run.font.underline = True
```

说明：
- 这份代码在 `write_note_two(...)` 里就用了下划线。

### 给 run 单独设置中文字体
```python
run._element.rPr.rFonts.set(qn('w:eastAsia'), '仿宋')
```

说明：
- 段落样式设了中文字体还不够时，可以对某个 `run` 单独补 `eastAsia`。
- 这份代码在注释文字里就是直接对 `run` 这样处理。

## 8. 写标题、正文、注释的典型模式

### 主标题
```python
headingmain = doc.add_paragraph('标题内容')
headingmain.style = 'MyTitleStyle'
headingmain.paragraph_format.alignment = WD_ALIGN_PARAGRAPH.CENTER
```

### 一级小标题
```python
heading1 = doc.add_paragraph(text)
heading1.style = 'MyHeadingStyle'
heading1.paragraph_format.alignment = WD_ALIGN_PARAGRAPH.LEFT
heading1.paragraph_format.left_indent = Pt(28.2)
```

### 二级标题
```python
heading = doc.add_paragraph(f'（{number}）{text}')
heading.style = 'MyMainStyle'
heading.paragraph_format.left_indent = Pt(28.2)
```

### 正文
```python
text = doc.add_paragraph(text)
text.style = 'MyMainStyle'
text.paragraph_format.first_line_indent = Pt(28.2)
text.paragraph_format.alignment = WD_ALIGN_PARAGRAPH.JUSTIFY
text.paragraph_format.line_spacing = 1.1
```

说明：
- 这几个函数本质上都是 `add_paragraph + style + paragraph_format (+ run.font)` 的组合。

## 9. 插入图片

### 直接插图
```python
doc.add_picture(image_path, width=Inches(6))
```

说明：
- `add_picture(...)` 是 `python-docx` 插图的标准写法。
- 宽度常用 `Inches(...)` 控制。

这份代码不是从磁盘路径插图，而是先把 `matplotlib` 图保存到内存：

```python
buf = io.BytesIO()
fig.savefig(buf, format="png", dpi=300, bbox_inches="tight")
buf.seek(0)
doc.add_picture(buf, width=width)
buf.close()
```

说明：
- `io.BytesIO()` 让图片先落到内存缓冲区，不必先生成临时 PNG 文件。
- `fig.savefig(...)` 把图表写进缓冲区。
- `buf.seek(0)` 很关键，不回到起点就读不到图片内容。
- 然后 `doc.add_picture(buf, ...)` 直接插入文档。

## 12. 保存 DOCX 并转 PDF

### 先保存 Word
```python
doc.save(docx_path)
```

说明：
- `python-docx` 原生负责保存 `.docx`。

### 用 `docx2pdf` 转 PDF
```python
from docx2pdf import convert

convert(docx_path, pdf_path, keep_active=True)
```

说明：
- `docx2pdf` 可以把已经保存好的 `.docx` 转成 `.pdf`。
- `keep_active=True` 表示尽量复用同一个 Word 实例，减少反复启动关闭 Word 的开销。

### Windows 下配合 COM 初始化
```python
import pythoncom

pythoncom.CoInitialize()
try:
    convert(docx_path, pdf_path, keep_active=True)
finally:
    pythoncom.CoUninitialize()
```

说明：
- 这份代码的一个关键实现细节就是显式初始化 COM。
- 在 Windows 环境里调起 Word 转 PDF 时，这一步能减少 COM 调用相关问题。

### 返回 PDF 二进制内容
```python
with open(pdf_path, "rb") as f:
    return f.read()
```

说明：
- 这样函数除了完成保存，还能把 PDF 文件内容直接返回，方便后续上传、响应接口或继续处理。

## 13. 读取 docx 文本

### 打开已有文档
```python
doc = Document(file_path)
```

### 提取非空段落文本
```python
paragraphs = [p.text.strip() for p in doc.paragraphs if p.text.strip()]
return "\n".join(paragraphs)
```

说明：
- `doc.paragraphs` 可以遍历所有段落。
- 这份代码只取非空段落，并拼成一个字符串返回。
- 这是读取 Word 正文内容时最直接的一种方式。

## 15. 一个实用理解

这份代码真正封装的，是 `python-docx` 里最常见的几个底层动作：

- `Document()` 创建 Word 文档
- `doc.styles.add_style(...)` 创建样式
- `doc.add_paragraph(...)` 创建段落
- `para.style` 和 `para.paragraph_format` 控制段落排版
- `para.add_run(...)` 和 `run.font` 控制局部文字样式
- `doc.add_picture(...)` 插入图片
- `doc.save(...)` 保存 Word
- `convert(...)` 把 Word 转成 PDF

如果后面你自己继续写框架，真正高频会复用的也是这些 API，尤其是：
- 中文字体的 `eastAsia` 设置
- 段落样式复用
- `run` 级别的局部排版
- 内存图像插入 Word
- Word 转 PDF 的 COM 初始化
