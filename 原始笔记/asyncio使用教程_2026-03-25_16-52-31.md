# asyncio使用教程

## 开始
如果底层函数是“同步阻塞”，执行
`await asyncio.to_thread(llm, messages)`

如果底层函数是“原生 async” -> 直接 `await`

## 中间过程
调用协程函数必须 `await`。
内部有 `await` 的函数必须是协程函数 `async def`。
`await` 需要一直向上传递。

## 最终
向上传递最后一个协程函数要放入 `asyncio.run(main())`。
`asyncio.run()` 是启动事件循环的入口。

## Semaphore 控制并发
`Semaphore` 控制同一个时间最多有几个协程在执行。
`asyncio.gather` 会同时调度所有任务，但不控制并发数量，只负责收集结果。它把全部的任务都塞入了asyncio.gather。
`async def call` 函数内部通过 `async with sem` 发放和回收令牌，只有拿到令牌的任务才会执行。

## 示例
```python
import asyncio

sem = asyncio.Semaphore(2)  # 控制并发=2

# 模拟同步阻塞函数（比如你现在的LLM）
def sync_llm(x):
    import time
    time.sleep(1)
    return f"result {x}"

# async包装（这里用 to_thread）
async def call(x):
    async with sem:  # 并发控制
        return await asyncio.to_thread(sync_llm, x)

# 批处理
async def main():
    tasks = [call(i) for i in range(5)]
    results = await asyncio.gather(*tasks)
    print(results)

# 启动
asyncio.run(main())
```

`await` 是核心 -> `async` 会向上传 -> `asyncio.run` 是入口 -> `Semaphore` 控并发。
