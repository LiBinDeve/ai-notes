# 图片插入单元格
```python
from openpyxl import Workbook
from openpyxl.drawing.image import Image as XLImage

wb = Workbook()
ws = wb.active #获取工作簿中的活动工作表（默认第一个工作表）。相当于：ws = wb['Sheet']

# 设置列宽和行高
ws.column_dimensions['B'].width = 11   # 字符单位
ws.row_dimensions[2].height = 65       # 磅

# 加载图片，设置尺寸（像素）
img = XLImage('野猪.png')
img.width  = 80
img.height = 80

# 锚定到单元格左上角
ws.add_image(img, 'B2')

wb.save('output.xlsx')


# 1. XLImage — openpyxl 内置的图片对象，直接传文件路径
# 2. img.width / img.height — 设置的是图片在 Excel 里的显示尺寸（像素），不是缩放比例，直接赋值覆盖即可
# 3. ws.add_image(img, 'B2') — 把图片锚定到 B2 单元格左上角，图片会"浮"在单元格上方，不是嵌入单元格内.意味着它只是位置固定在这个单元格左上角，但本质上是独立的浮动对象。对这个单元格进行输入、删除都不对它产生影响。

# 注意： 行高/列宽和图片尺寸是两套独立的单位，需要手动对齐大小，Excel 不会自动适应。
```
