# argparse
argparse 是 Python 自带的命令行参数解析库。

## 创建解析器parser
description是脚本说明文字，运行脚本时，命令行会显示。
```python
import argparse

parser = argparse.ArgumentParser(description="分析聊天记录并更新任务表")
```

## 添加普通参数
required=True是代表这个参数是必填的，用户再命令行不填就会报错。
type=int：命令行输入默认都是字符串，也就是说，命令行输入参数是字符串的不用加双引号，因为默认就是字符串。当需要是整数时，添加type=int，argparse 会自动把字符串转成整数，args.limit读取的就是整数值。如果输入的参数不能转化成整数，也会报错，如abc.
default：默认值
```python
parser.add_argument("--nickname", required=True, help="客户昵称（对应聊天记录文件夹名）")
parser.add_argument("--limit", type=int, default=20, help="消息数量")
```

## 解析参数
parse_args把用户在命令行输入的参数解析成一个类对象。就可以这种形式获取了：args.limit。

```python
args = parser.parse_args()
```

## 子命令
### 添加子命令
```python
add_parser = subparsers.add_parser("add", help="添加客户")
```

### 给子命令添加参数
```python
add_parser.add_argument("--wechat_id", required=True, help="客户微信号")
add_parser.add_argument("--nickname", default="", help="客户昵称")
add_parser.add_argument("--group_name", default="", help="微信群名")
add_parser.add_argument("--tags", default="", help="客户标签")
add_parser.add_argument("--notes", default="", help="备注")
```

## 打印帮助信息
如果触发，就再命令行终端显示有哪些命令可以用。

```python
parser.print_help()
```

## 应用方式
### 普通
```python
import argparse


def main(nickname: str):
    print("开始处理客户：", nickname)


if __name__ == "__main__":
    parser = argparse.ArgumentParser(description="分析聊天记录并更新任务表")

    parser.add_argument(
        "--nickname",
        required=True,
        help="客户昵称（对应聊天记录文件夹名）"
    )

    args = parser.parse_args()

    main(args.nickname)
```

```bash
python analyze_chat.py --nickname 张三
```

### 子命令
```python
import argparse


def add_customer_cmd(args):
    print("添加客户")
    print("微信号：", args.wechat_id)
    print("昵称：", args.nickname)


def delete_customer_cmd(args):
    print("删除客户：", args.nickname)


def list_customer_cmd(args):
    print("查看全部客户")


def main():
    parser = argparse.ArgumentParser(description="客户管理命令行工具")

    subparsers = parser.add_subparsers(dest="command")

    # add 子命令
    add_parser = subparsers.add_parser("add", help="添加客户")
    add_parser.add_argument("--wechat-id", dest="wechat_id", required=True, help="客户微信号")
    add_parser.add_argument("--nickname", default="", help="客户昵称")
    add_parser.add_argument("--tags", default="", help="客户标签")
    add_parser.set_defaults(func=add_customer_cmd)

    # delete 子命令
    delete_parser = subparsers.add_parser("delete", help="删除客户")
    delete_parser.add_argument("--nickname", required=True, help="要删除的客户昵称")
    delete_parser.set_defaults(func=delete_customer_cmd)

    # list 子命令
    list_parser = subparsers.add_parser("list", help="查看全部客户")
    list_parser.set_defaults(func=list_customer_cmd)

    args = parser.parse_args()

    if hasattr(args, "func"):
        args.func(args)
    else:
        parser.print_help()


if __name__ == "__main__":
    main()
```

```bash
python manage_customers.py add --wechat_id wxid_001 --nickname 张三
python manage_customers.py delete --nickname 张三
python manage_customers.py list
```
