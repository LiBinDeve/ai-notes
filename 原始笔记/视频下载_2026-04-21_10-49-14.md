# B站视频下载

开源项目链接：https://github.com/nilaoda/BBDown

## 使用方法

第一步：建项目目录

第二步：命令行运行 `dotnet new tool-manifest`，在项目目录会建立一个 json 文件。

第三步：安装命令：

```powershell
dotnet tool install BBDown
```

安装完后安装文件在 `C:\Users\Young\.nuget\packages\`，项目的 json 文件存放了可用工具的描述。

第四步：测试是否可运行：

```powershell
dotnet BBDown -h
```

第五步：视频下载：

```powershell
dotnet BBDown "下载链接"
```

# 全站视频下载

开源项目链接：https://github.com/yt-dlp/yt-dlp

## 使用方法

第一步：下载 exe 文件，不用安装。

第二步：把 exe 文件的路径放入系统环境变量：`E:\yt-dlp\`

第三步：打开命令行运行命令下载视频：

```powershell
yt-dlp https://www.youtube.com/watch?v=jGLJWP1Ysmw
```

## 特殊说明

下载 YouTube 时有时要 cookies 验证。

需要从 Chrome Web Store 下载一个浏览器扩展去获取下载 cookies。

扩展名：`Get cookies.txt LOCALLY`

扩展链接：https://chromewebstore.google.com/detail/get-cookiestxt-locally/cclelndahbckbenkjhflpdbgdldlbecc
