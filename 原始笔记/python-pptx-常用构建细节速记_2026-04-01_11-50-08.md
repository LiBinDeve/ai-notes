# python-pptx 常用构建细节速记

## 来源
- 源文件：`E:\笔记-L（本地知识仓库）\参考资料\python-pptx\ppt_scaffold.py`

## 1. 创建一个 PPT

### 创建演示文稿对象
```python
from pptx import Presentation

prs = Presentation()
```

说明：
- `Presentation()` 就是新建一个 PPT 对象。
- 后续所有页面、形状、文本框都挂在这个对象下面。

### 设置页面尺寸
```python
from pptx.util import Inches

prs.slide_width = Inches(13.333)
prs.slide_height = Inches(7.5)
```

说明：
- `slide_width` 和 `slide_height` 控制整份 PPT 的画布大小。
- 这里用 `Inches(...)`，表示传给库的是“英寸单位”。
- 16:9 页面常见写法就是 `13.333 x 7.5`。

## 2. 创建一页幻灯片

### 添加空白页
```python
slide = prs.slides.add_slide(prs.slide_layouts[6])
```

说明：
- `prs.slides.add_slide(...)` 是新增页面。
- `prs.slide_layouts[6]` 是空白布局。
- 如果你要完全自己控制版式，通常就用空白页。

## 3. 颜色设置

### RGB 颜色对象
```python
from pptx.dml.color import RGBColor

RGBColor(44, 92, 197)
```

说明：
- `python-pptx` 的颜色不是直接塞元组，而是要转成 `RGBColor`。
- 这个脚手架里封装了一个辅助函数：

```python
def rgb(color):
    return RGBColor(*color)
```

## 4. 创建文本框

### 添加文本框
```python
shape = slide.shapes.add_textbox(
    Inches(x), Inches(y), Inches(w), Inches(h)
)
```

说明：
- `slide.shapes.add_textbox(...)` 用来放文字。
- 参数分别是：左上角 `x/y`，宽 `w`，高 `h`。
- 坐标和尺寸通常都用 `Inches(...)`。

## 5. 设置文本框背景和边框

### 背景透明
```python
shape.fill.background()
```

说明：
- 让文本框背景透明，不填充颜色。

### 背景纯色
```python
shape.fill.solid()
shape.fill.fore_color.rgb = RGBColor(245, 247, 250)
```

说明：
- `fill.solid()` 先声明“使用纯色填充”。
- 再给 `fore_color.rgb` 赋值。

### 无边框
```python
shape.line.fill.background()
```

说明：
- 边框隐藏。

### 有边框
```python
from pptx.util import Pt

shape.line.color.rgb = RGBColor(220, 224, 230)
shape.line.width = Pt(1.0)
```

说明：
- 边框颜色用 `shape.line.color.rgb`
- 边框粗细用 `Pt(...)`

## 6. 设置文本内容和文字属性

### 拿到文本框的 text_frame
```python
tf = shape.text_frame
```

说明：
- 文本框里的文字内容由 `text_frame` 管。

### 清空默认段落
```python
tf.clear()
```

说明：
- 新建文本框通常会带一个默认段落。
- `clear()` 可以先清掉，再自己写内容。

### 开启自动换行
```python
tf.word_wrap = True
```

### 设置垂直对齐
```python
from pptx.enum.text import MSO_ANCHOR

tf.vertical_anchor = MSO_ANCHOR.TOP
```

说明：
- 控制文本在文本框内部的垂直位置。
- 常见值有顶部、中部等。

### 设置文本框内边距
```python
tf.margin_left = Inches(0.05)
tf.margin_right = Inches(0.05)
tf.margin_top = Inches(0.03)
tf.margin_bottom = Inches(0.03)
```

说明：
- 这些不是页面坐标，而是文本框内部留白。

## 7. 设置段落和字体

### 取第一段
```python
p = tf.paragraphs[0]
```

说明：
- `text_frame` 里是按“段落”组织的。
- 单段文本时直接拿第一个段落即可。

### 设置段落对齐
```python
from pptx.enum.text import PP_ALIGN

p.alignment = PP_ALIGN.LEFT
```

说明：
- 控制左对齐、居中、右对齐。

### 添加文字 run
```python
run = p.add_run()
run.text = text
```

说明：
- 段落里真正承载文字的是 `run`。
- 如果同一段里要混合不同字体样式，可以加多个 `run`。

### 设置字体
```python
from pptx.util import Pt

run.font.name = "Microsoft YaHei"
run.font.size = Pt(20)
run.font.bold = True
run.font.color.rgb = RGBColor(34, 34, 34)
```

说明：
- 字体名：`run.font.name`
- 字号：`run.font.size = Pt(...)`
- 加粗：`run.font.bold = True/False`
- 字色：`run.font.color.rgb = RGBColor(...)`

## 8. 创建矩形等形状

### 添加矩形
```python
from pptx.enum.shapes import MSO_AUTO_SHAPE_TYPE

shape = slide.shapes.add_shape(
    MSO_AUTO_SHAPE_TYPE.RECTANGLE,
    Inches(x), Inches(y), Inches(w), Inches(h)
)
```

说明：
- `add_shape(...)` 用于创建自选图形。
- `MSO_AUTO_SHAPE_TYPE.RECTANGLE` 表示矩形。
- 后续填充色、边框色的设置方式和文本框类似。

## 9. 创建直线

### 添加连接线
```python
from pptx.enum.shapes import MSO_CONNECTOR

line = slide.shapes.add_connector(
    MSO_CONNECTOR.STRAIGHT,
    Inches(x1), Inches(y1), Inches(x2), Inches(y2)
)
```

说明：
- `add_connector(...)` 可画线。
- `MSO_CONNECTOR.STRAIGHT` 表示直线。
- 线条样式同样通过 `line.line` 设置。

### 设置线条颜色和粗细
```python
line.line.color.rgb = RGBColor(44, 92, 197)
line.line.width = Pt(1.5)
```

## 10. 插入图片

### 添加图片
```python
slide.shapes.add_picture(
    str(image_path),
    Inches(x),
    Inches(y),
    width=Inches(w),
    height=Inches(h),
)
```

说明：
- `add_picture(...)` 用于插图。
- `image_path` 可以是字符串或 `Path`。
- `width`、`height` 可以只传一个，也可以都传。
- 不传时通常按图片原比例。

## 11. 保存 PPT

### 输出文件
```python
prs.save(output_path)
```

说明：
- 所有页面添加完成后，调用 `save(...)` 落盘。

## 12. 这份脚手架里最值得直接复用的具体写法

### 新建 PPT
```python
prs = Presentation()
prs.slide_width = Inches(13.333)
prs.slide_height = Inches(7.5)
```

### 新建空白页
```python
slide = prs.slides.add_slide(prs.slide_layouts[6])
```

### 新建文本框并设字体
```python
shape = slide.shapes.add_textbox(Inches(x), Inches(y), Inches(w), Inches(h))
tf = shape.text_frame
tf.clear()
tf.word_wrap = True

p = tf.paragraphs[0]
run = p.add_run()
run.text = text
run.font.name = "Microsoft YaHei"
run.font.size = Pt(20)
run.font.bold = False
run.font.color.rgb = RGBColor(34, 34, 34)
```

### 设文本框背景和边框
```python
shape.fill.solid()
shape.fill.fore_color.rgb = RGBColor(245, 247, 250)

shape.line.color.rgb = RGBColor(220, 224, 230)
shape.line.width = Pt(1.0)
```

### 新建矩形块
```python
shape = slide.shapes.add_shape(
    MSO_AUTO_SHAPE_TYPE.RECTANGLE,
    Inches(x), Inches(y), Inches(w), Inches(h)
)
```

### 新建直线
```python
line = slide.shapes.add_connector(
    MSO_CONNECTOR.STRAIGHT,
    Inches(x1), Inches(y1), Inches(x2), Inches(y2)
)
line.line.color.rgb = RGBColor(44, 92, 197)
line.line.width = Pt(1.5)
```

### 插入图片
```python
slide.shapes.add_picture(str(image_path), Inches(x), Inches(y), width=Inches(w))
```

## 13. 一个实用理解

这个脚手架真正封装的，不是“PPT 框架思想”，而是把 `python-pptx` 最常写的底层操作收成了几个短函数：

- `Presentation()` 负责创建 PPT
- `prs.slides.add_slide(...)` 负责创建页
- `slide.shapes.add_textbox(...)` 负责放文字
- `slide.shapes.add_shape(...)` 负责放矩形等图形
- `slide.shapes.add_connector(...)` 负责画线
- `slide.shapes.add_picture(...)` 负责插图
- `shape.fill / shape.line / text_frame / paragraph / run.font` 负责样式细节

后面你自己写框架时，真正高频会用到的就是这些 API。
