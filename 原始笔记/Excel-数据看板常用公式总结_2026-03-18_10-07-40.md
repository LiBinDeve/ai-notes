# Excel 数据看板常用公式总结

这是一份适合做数据看板的 Excel 常用公式速查笔记。目标不是死记公式，而是知道：**这个公式是干什么的、怎么理解、常见坑在哪里。**

---

## 1. 获取下一次最近培训的信息

公式：

```excel
=INDEX(主培训计划表!G2:G100,MATCH(MIN(IF(主培训计划表!D2:D100>=TODAY(),主培训计划表!D2:D100)),主培训计划表!D2:D100,0))
```

作用：

从今天开始，找到**最近的一次培训日期**，再返回这次培训对应的课程名称。

理解顺序：

1. `TODAY()`：获取今天日期
2. `IF(D列>=TODAY(), D列)`：筛出今天及未来的培训日期
3. `MIN(...)`：取最早的那个未来日期
4. `MATCH(...)`：找到这个日期在 D 列中的位置
5. `INDEX(...)`：根据位置，到 G 列返回对应课程名

一句话理解：

> 先找“最近的未来日期”，再取这一天对应的课程。

## 2. 统计非空单元格数量

公式：

```excel
=COUNTA(主培训计划表!A:A)-1
```

作用：

统计 A 列中有内容的单元格数量。

说明：

- `COUNTA` 统计的是**非空单元格**
- `-1` 一般是为了去掉表头

---

## 3. 单条件计数

公式：

```excel
=COUNTIF(主培训计划表!M:M,"已完成")
```

作用：

统计 M 列中“已完成”的数量。

公式结构：

```excel
COUNTIF(范围, 条件)
```

一句话理解：

> 在一列里，数一数满足某个条件的有多少个。

---

## 4. 字符串拼接

公式：

```excel
="图三："&A22&"课程合格率"
```

作用：

把多个文本拼接成一句完整的话。

例如：

如果 A22 是“电气基础”，结果就是：

```text
图三：电气基础课程合格率
```

说明：

- `&` 表示把文字连接起来
- 适合做图表标题、说明文字、标签名称

---

## 5. VLOOKUP 查找

公式：

```excel
=VLOOKUP(A22,培训进度跟踪表!B2:K41,4,FALSE)
```

作用：

按关键字找到对应行，再返回这一行中指定列的值。

公式结构：

```excel
VLOOKUP(查找值, 区域, 列序号, 是否精确匹配)
```

解释：

- `A22`：要查找的值
- `B2:K41`：查找区域
- `4`：返回区域中的第 4 列
- `FALSE`：精确匹配

一句话理解：

> 先找到这一行，再取这一行某一列的值。

注意：

`VLOOKUP` 只能在**区域的第一列**查找目标值。

---

## 6. 多条件计数

公式：

```excel
=COUNTIFS(主培训计划表!A:A,"第一阶段",主培训计划表!H:H,"电气基础",主培训计划表!M:M,"已完成")
```

```excel
=COUNTIFS(主培训计划表!A:A,"第二阶段",主培训计划表!H:H,"机械基础",主培训计划表!M:M,"已完成")
```

作用：

统计**多个条件同时满足**的记录数量。

公式结构：

```excel
COUNTIFS(范围1,条件1,范围2,条件2,...)
```

一句话理解：

> 把多个筛选条件同时套上，再统计数量。

---

## 7. FILTER 条件筛选

公式：

```excel
=FILTER(培训进度跟踪表!B2:B41,培训进度跟踪表!I2:I41<1,"无未达标课程")
```

作用：

按条件筛选出符合要求的数据，并返回对应列的结果。

公式结构：

```excel
FILTER(返回区域, 筛选条件, 无结果时返回的内容)
```

解释：

这条公式表示：

- 在 I 列中找出小于 1 的行
- 返回这些行在 B 列中的值
- 如果没有结果，就显示“无未达标课程”

一句话理解：

> 先筛选，再返回筛出来的结果。

## 8. 直接取对应单元格的值

公式：

```excel
=主培训计划表!D2
=主培训计划表!G2
=主培训计划表!M2
=主培训计划表!J2
```

作用：

直接引用另一张表中指定单元格的内容。

一句话理解：

> 直接把别的单元格的值拿过来显示。

## 9. 下拉列表建立

```text
数据 → 下拉列表 / 数据验证 → 从单元格选择下拉选项
```

## 11. TEXTJOIN 函数

公式：

```excel
=TEXTJOIN("、",TRUE,A1:A5)
```

作用：

把多个文本按照指定分隔符拼接成一个字符串。

公式结构：

```excel
TEXTJOIN(分隔符, 是否忽略空单元格, 文本1, [文本2], ...)
```

解释：

- 第 1 个参数：分隔符，例如 `、`
- 第 2 个参数：是否忽略空单元格，`TRUE` 表示忽略
- 后面参数：要拼接的内容

例如：

```text
苹果、香蕉、梨
```

一句话理解：

> 把多个结果合并成一句话显示。

## 12. 复杂公式常见坑

例如下面这条公式：

```excel
=INDEX(主培训计划表!G2:G100,MATCH(MIN(IF(主培训计划表!D2:D100>=TODAY(),主培训计划表!D2:D100)),主培训计划表!D2:D100,0))
```

### 坑 1：没有未来日期

如果 D 列中没有今天及未来的日期，公式可能报错。

处理方法：

```excel
=IFERROR(原公式,"暂无后续培训")
```

作用：

如果公式报错，就显示“暂无后续培训”。

---

### 坑 2：日期不是真正的日期格式

如果 D 列看起来像日期，但本质是文本，那么：

```excel
>=TODAY()
```

比较时就可能出错。

处理建议：

确保 D 列是 Excel 真实日期格式，而不是文本。

---

### 坑 3：日期重复

如果同一天有多条培训记录，`MATCH(...,0)` 只会返回**第一条**。

也就是说：

> 默认只取最先出现的那条记录。

如果你想把同一天的课程全部显示出来，可以改用：

```excel
=TEXTJOIN("、",TRUE,FILTER(主培训计划表!G2:G100,主培训计划表!D2:D100=MIN(IF(主培训计划表!D2:D100>=TODAY(),主培训计划表!D2:D100)),""))
```

作用：

把同一天的多门课程全部筛出来，再拼接到一起显示。

---

## 13. 一页总结

做 Excel 数据看板时，最常用的公式可以分成这几类：

| 类型 | 常用函数 | 作用 |
|---|---|---|
| 查找 | `INDEX`、`MATCH`、`VLOOKUP` | 找到对应记录并取值 |
| 统计 | `COUNTA`、`COUNTIF`、`COUNTIFS` | 统计数量 |
| 筛选 | `FILTER` | 按条件返回结果 |
| 文本处理 | `&`、`TEXTJOIN` | 拼接文字 |
| 错误处理 | `IFERROR` | 避免公式报错 |

最终记忆：

- `INDEX + MATCH`：先定位，再取值
- `COUNTIF / COUNTIFS`：按条件计数
- `FILTER`：按条件筛出结果
- `TEXTJOIN`：把多个结果拼成一句话
- `IFERROR`：公式报错时给出友好提示
