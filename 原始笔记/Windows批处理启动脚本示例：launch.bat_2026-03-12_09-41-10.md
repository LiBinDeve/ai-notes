# Windows批处理启动脚本示例：`launch.bat`

# 参考文件路径："\参考资料\launch\launch.bat"

## 完整代码

```batch
@echo off
cd /d %~dp0

call venv\Scripts\activate.bat
nanobot agent

pause
```

## 逐行代码解释

### 第1行：`@echo off`
- **功能**：关闭命令回显，使脚本运行时不会显示每条命令本身
- **作用**：让输出更整洁，只显示命令执行结果，不显示执行的命令文本
- **对比**：如果没有这行，会看到每行代码先显示出来再执行

### 第2行：`cd /d %~dp0`
- **功能**：切换到批处理文件所在的目录
- **分解说明**：
  - `%0`：当前批处理文件的完整路径
  - `%~dp0`：提取`%0`的驱动器和路径部分（Drive + Path）
  - `/d`：允许切换到不同驱动器（如从C盘到D盘）
- **用途**：确保脚本总是在自身所在目录运行，避免路径问题

### 第3行：空行
- **功能**：增加可读性，分隔不同逻辑块
- **作用**：在批处理文件中，空行没有实际功能，但能提高代码可读性

### 第4行：`call venv\Scripts\activate.bat`
- **功能**：激活Python虚拟环境
- **说明**：
  - `venv\Scripts\activate.bat`：Windows下Python虚拟环境的激活脚本
  - `call`：调用另一个批处理文件并返回，而不是替换当前进程
- **用途**：激活项目特定的Python环境，确保使用正确的Python版本和包

### 第5行：`nanobot agent`
- **功能**：运行nanobot智能体
- **说明**：
  - `nanobot`：命令行工具名称
  - `agent`：启动智能体模式
- **用途**：启动AI助手程序

### 第6行：空行
- **功能**：增加可读性

### 第7行：`pause`
- **功能**：暂停脚本执行，等待用户按键
- **作用**：
  - 防止命令窗口在执行完成后立即关闭
  - 允许查看程序输出结果
  - 对于调试和测试特别有用

## 脚本工作原理图示

```
启动脚本
    ↓
切换到脚本所在目录（确保路径正确）
    ↓
激活Python虚拟环境（隔离依赖）
    ↓
启动nanobot智能体（主程序）
    ↓
等待用户按键（防止窗口关闭）
    ↓
结束
```
